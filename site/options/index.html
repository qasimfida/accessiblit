API reference

Configure Accessiblit.

Pass an options object to init. Invalid configuration is reported with a console warning and resolved safely; it should not throw into the host page.

The table can scroll horizontally on a narrow screen. Focus it to use the arrow keys.

Options accepted by init
Option Default Meaning
position 'bottom-right' Choose bottom-right, bottom-left, top-right or top-left. The names refer to physical corners.
features All 18 features An allowlist of FeatureId values. Leave it out to include the complete catalogue.
exclude [] Feature IDs to remove from the allowlist.
storageKey 'accessiblit:v1' The one localStorage key used for settings.
persist true Set false to avoid reading or writing persistent settings.
shortcut 'Alt+A' A modifier-based shortcut matched by physical key code, or false to disable it.
zIndex 2147483000 Stacking preference. Native top-layer order still applies.
offset { x: 16, y: 16 } Horizontal and vertical edge offsets in CSS pixels.
nonce Not set An owner-supplied CSP nonce for fallback style elements. Script loading must also satisfy your policy.
messages English defaults A Partial<Messages> object for interface copy, labels, descriptions and announcements.
dyslexiaFontUrl Not set An optional owner font reference, never fetched by the widget. Preload and register AccessiblitDyslexia faces before init.
onChange Not set An opt-in callback receiving { id, value } for setting changes. No visitor identity is added.

Instance lifecycle

Keep the returned instance when your integration owns the widget. Calling init again destroys the previous instance. Imports are SSR-safe, and init is inert without a DOM. 

import { init } from '@qasimfida/accessiblit';

const widget = init({ position: 'bottom-right' });
widget.open();
widget.close();
widget.toggle();
widget.setFeature('fontSize', 120);
const state = widget.getState();
widget.reset();
widget.destroy();

Personalisation supports visitor choice. It does not make a site conformant by itself.
