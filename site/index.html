Accessibility personalisation

A page that works your way.

Eighteen controls for text, colour and navigation in one lightweight widget. Give visitors choices without accounts, cookies or tracking.

  • 18 visitor controls

Try it on this page

Make room for your reading preferences.

This demo loads the real widget from this repository's local build. Production integrations use npm, a CDN script or a self-hosted file.

Take a different pace

A clear page gives readers room to choose their own pace. Try larger text, different spacing or a reading guide. You can combine settings and use Reset all to return to the defaults.

Read about the boundaries of page adjustments before adding the widget to your own site.

The feature catalogue

18 controls, grouped by purpose.

Controls are generated from the widget's feature registry. Your integration can allow or exclude features through its options.

Content

Font size

Scale text from 80% to 200%, in 10-point steps.

Line height

Choose the original spacing, 1.5, 1.75 or 2.

Letter spacing

Choose original spacing, 0.12em, 0.16em or 0.2em.

Word spacing

Choose original spacing, 0.16em, 0.24em or 0.32em.

Text alignment

Align eligible text blocks left, centre or right without treating navigation and layout containers as text blocks.

Content scale

Zoom the page layout from 100% to 200%.

Readable font

Choose a system stack or an owner-preloaded dyslexia-friendly font, with a system fallback.

Colour and contrast

Dark mode

Use a dark HTML palette with light text.

High contrast

Use a strong text/background palette; this takes priority when dark mode is also enabled.

Monochrome

Remove colour from eligible page content.

Low saturation

Reduce colour intensity; monochrome takes priority when both are enabled.

Navigation and orientation

Reading guide

Follow a pointer, touch point or keyboard focus with a horizontal guide.

Reading mask

Keep a reading strip clear while gently dimming the surrounding page.

Highlight links

Outline and underline links, using more than colour alone.

Highlight headings

Outline headings and show a visual level badge.

Larger cursor

Choose 32px or 48px pointers on fine-pointer devices. Touch-only devices keep their native behaviour.

Stop animations

Pause CSS animation, remove transitions and smooth scrolling, and pause autoplay video.

Focus highlight

Emphasise keyboard focus with a two-tone ring.

Visitor choice is one part of accessibility.

Personalisation does not repair headings, labels, keyboard flows or inaccessible content. Build and test the underlying site as well.

Read the FAQ and privacy notes

Personalisation supports visitor choice. It does not make a site conformant by itself.
