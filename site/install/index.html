Integration guide

The same core API works with a script tag, JavaScript modules and React applications. Mount one instance per document.

CDN script tag

Place the script before the init call. The library exposes the Accessiblit global and can wait for the document body. 

<script src="https://cdn.jsdelivr.net/npm/@qasimfida/accessiblit@0.0.0/dist/accessiblit.min.js"></script>
<script>
  Accessiblit.init();
</script>

npm and ESM

Install the package after a public release, then import the module from your application entry. 

npm install @qasimfida/accessiblit
import { init } from '@qasimfida/accessiblit';

const widget = init({ position: 'bottom-left' });
// Call widget.destroy() when removing this integration.

React

React is an optional peer dependency, version 17 or newer. An effect keeps DOM work on the client and cleans up the instance it created, including under StrictMode. 

npm install @qasimfida/accessiblit react react-dom
import { useEffect } from 'react';
import { init } from '@qasimfida/accessiblit';

export default function Accessibility() {
  useEffect(() => {
    const widget = init({ position: 'bottom-right' });
    return () => widget.destroy();
  }, []);
  return null;
}

Next.js App Router

Create a client component and render it from your layout. The separate React entry keeps React out of the core browser bundle. 

'use client';

import { AccessiblitWidget } from '@qasimfida/accessiblit/react';

export default function Accessibility() {
  return <AccessiblitWidget position="bottom-right" />;
}

Self-hosted file

Copy dist/accessiblit.min.js from your built package to your own static assets. This example assumes you serve it at /vendor/accessiblit.min.js. A strict CSP must also authorise your script and supply an owner nonce when fallback styles need one. 

<script src="/vendor/accessiblit.min.js"></script>
<script>
  Accessiblit.init({ position: 'bottom-right' });
</script>

Private distribution

Tarball

Build and pack the source, then give the resulting .tgz file to your consuming project. Adjust the path to the file you received. 

npm run build
npm pack
# In the consuming project:
npm install ./path/to/qasimfida-accessiblit-0.0.0.tgz

Git source

For private distribution, use these build-and-pack steps with your team’s private mirror; the public repository below is a reproducible example. A Git checkout contains source rather than committed dist files. Build it before packing; do not assume a bare Git dependency includes built artifacts. 

git clone https://github.com/qasimfida/accessiblit.git
cd accessiblit
git checkout phase-7-complete
npm ci
npm run build
npm pack

Private registry

Your team can distribute the package through its registry and normal credential management. Replace the example registry URL with yours; no credentials belong in page source or these snippets. 

npm install @qasimfida/accessiblit --registry=https://registry.example.invalid

Personalisation supports visitor choice. It does not make a site conformant by itself.
