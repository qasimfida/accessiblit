FAQ and privacy

Know what the widget does.

Does adding a widget make a site conformant?

No. A widget helps visitors personalise a page, but it does not make a site conformant by itself. The underlying content, semantics, navigation and interactions still need accessible design and testing.

What stays in the browser?

Accessiblit sets no cookies, includes no tracking or analytics, and makes no runtime requests. Settings use localStorage under one key, accessiblit:v1 by default. Blocked storage falls back to memory. Owners can change the key or set persist: false.

The settings contain feature choices, not page text or visitor identity. Reset all restores defaults. To remove a stored key entirely, use your browser's site-data controls. An owner's optional onChange callback is separate integration code; the widget does not send settings to a server.

Will every page adjustment work everywhere?

Host layouts differ. Fixed-height boxes, unusual CSS, native modals and embedded content need integration testing. Page styles do not automatically cross iframe or other components' shadow-tree boundaries. The widget does not repair markup.

Stopping animations covers CSS animation, transitions, smooth scrolling and autoplay video. GIFs, canvas and JavaScript-driven motion cannot all be stopped by those rules. Paused videos remain paused until the visitor or site resumes playback.

Does it download a font?

No font file is bundled or fetched. Readable mode uses a system stack. Dyslexia-friendly mode uses an owner's already loaded AccessiblitDyslexia font when configured; otherwise it uses a documented system fallback. It is a presentation choice, not a claim of medical benefit.

How does keyboard operation work?

Alt+A opens or closes the options by default. The shortcut is configurable and can be disabled. Escape closes the panel and returns focus to its launcher. The panel is non-modal: Tab can leave it.

Do I need React?

No. The core is dependency-free. The optional React entry provides AccessiblitWidget and useAccessiblit for React 17 or newer; React is not included in the core browser bundle.

What happens when I remove it?

Call the owned instance's destroy method when unmounting your integration. It removes its nodes, styles, classes, attributes and listeners. Stored preferences intentionally remain, and paused videos do not resume automatically.

Personalisation supports visitor choice. It does not make a site conformant by itself.
